Sistema de Controle de Entrada e Saída – SENAI Lençóis Paulista
Descrição do Projeto

Este projeto consiste em um sistema de gerenciamento de entrada atrasada e saída adiantada de alunos, desenvolvido para a Escola SENAI de Lençóis Paulista.

O sistema permite que alunos solicitem entradas e saídas antecipadas, enviando automaticamente notificações para responsáveis, professores e coordenadores. Após a autorização, o aluno recebe um QR Code para validação na portaria, garantindo segurança, organização e agilidade no processo.

O projeto foi desenvolvido como projeto acadêmico, mas com aplicação prática real, oferecendo aprendizado em integração de sistemas, desenvolvimento web e experiência do usuário.

Funcionalidades

Solicitação de entrada atrasada e saída antecipada pelos alunos.

Aprovação automática enviada para responsáveis, professores e coordenadores.

Geração de QR Code para validação na portaria.

Controle de autorização em tempo real.

Interface amigável para usuários e administradores.
